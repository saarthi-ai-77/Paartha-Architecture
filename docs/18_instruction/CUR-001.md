## 1. Primary Research Question: Computational Requirement vs Educational Convenience

### Theorem 1.1 (Curriculum Structure is a Computational Requirement)
> In a bounded, non-pre-trained artificial cognitive architecture ($\text{Memory Capacity } C < \infty, \text{ Pretraining Tokens } = 0$), curriculum dependency ordering is a **formal computational requirement** for sustained competence acquisition, NOT an educational convenience.

#### Formal Computational Proof:
1. **Rule Grounding Precondition**: A Constraint-Rule $c \in S_{invariants}$ of the form $\forall x (P_{cond}(x, T_{cond}) \implies P_{impl}(x, T_{impl}))$ requires category symbol $T_{cond}$ to exist in entity store $\mathcal{V}_E$. If a lesson presents rule $c$ at episode $t_1$ *before* the prerequisite category $T_{cond}$ has been taught at episode $t_0 > t_1$, rule $c$ cannot be bound to any entity, causing **Failure Mode FL-2a (Ungrounded Invariant)**.
2. **Capacity Overload & Eviction Gate**: In a bounded episodic substrate ($S_{episodic}$ capacity $C$), presenting complex procedural commands without pre-consolidating prerequisite primitive mappings causes memory saturation ($N > C$) and premature eviction (Failure Mode PM-1) before $S_{semantic}$ consolidation completes.
3. **Conclusion**: Valid cognitive learning requires lessons to be presented in a strictly valid topological ordering over the Prerequisite Dependency Graph $\mathcal{G}_{curriculum}$.

- **Epistemic Status**: **Reasoned Hypothesis** (Formal computational proof derived from CPA-001 and UIT-001).

## 2. Prerequisite Dependency Graph ($\mathcal{G}_{curriculum}$)

Curriculum structure is formalized as a Directed Acyclic Graph (DAG):
$$\mathcal{G}_{curriculum} = (V_{\text{lessons}}, E_{\text{prereq}})$$

Where:
- $V_{\text{lessons}} = \{ \mathcal{L}_1, \mathcal{L}_2, \dots, \mathcal{L}_m \}$: Set of discrete instructional lessons.
- $E_{\text{prereq}} \subset V_{\text{lessons}} \times V_{\text{lessons}}$: Directed edges $(\mathcal{L}_i, \mathcal{L}_j)$ indicating that lesson $\mathcal{L}_i$ is a strict computational prerequisite for lesson $\mathcal{L}_j$ ($\mathcal{L}_i \prec \mathcal{L}_j$).

## 3. Topological Lesson Sequencing Algorithm

To guarantee zero ungrounded invariant failures (FL-2a), mentor instruction must execute a topological sort over $\mathcal{G}_{curriculum}$:

```python
def generate_valid_lesson_sequence(graph):
    # Standard Kahn's algorithm for topological sorting
    in_degree = {u: 0 for u in graph.nodes}
    for u, v in graph.edges:
        in_degree[v] += 1
    queue = [u for u in graph.nodes if in_degree[u] == 0]
    sequence = []
    while queue:
        u = queue.pop(0)
        sequence.append(u)
        for v in graph.neighbors(u):
            in_degree[v] -= 1
            if in_degree[v] == 0:
                queue.append(v)
    assert len(sequence) == len(graph.nodes), "Cyclic dependency detected in curriculum graph!"
    return sequence
```

## 5. Experimental Roadmap for ACA-1 (EXP-027 Design)

**EXP-027: Multi-Category Curriculum Learning Trial (ACA-1 Design)**

- **Primary Research Question**: Can an expanded ACA model (**ACA-1**) acquire all 5 UIT-001 knowledge categories sequentially across a 20-lesson structured curriculum without experiencing cross-category interference or historical forgetting?
- **Experimental Setup**:
  - *Model*: ACA-1 runtime incorporating CPA-001 INV-1 process triggers, KRS-001 knowledge graphs, and LRS-001 learning protocols.
  - *Curriculum*: 20 lessons structured in a valid topological ordering over $\mathcal{G}_{curriculum}$.
  - *Evaluation*: Evaluates retention, transfer, counterfactual reasoning, and clarification accuracy across all 5 benchmark suites (BM-CAT1 to BM-CAT5) after completing the 20-lesson sequence.
- **Falsification Criteria**: If ACA-1 suffers catastrophic forgetting on Category 1 facts after learning Category 3 procedural skills, or fails to emit clarification requests on Category 5 unknown queries, the curriculum learning hypothesis is falsified.
