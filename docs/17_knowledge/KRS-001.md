# KRS-001: Knowledge Representation Specification

**Role note:** Produced under the Chief Systems Engineer role for **ACA-0 ("The First Cognitive Prototype")**. KRS-001 establishes the canonical computational representation of knowledge derived and verified by ACA-0 (`runtime/aca0/`) under **ILP-001** and **EXP-026**.

KRS-001 defines how natural language instructions from a mentor are transformed into executable computational knowledge graphs, supporting direct recall, explanation synthesis, transfer learning, counterfactual simulation, and interactive clarification.

---

## 1. Mathematical Knowledge Model

A Knowledge Graph $\mathcal{K}$ in KRS-001 is represented as a formal 3-tuple:
$$\mathcal{K} = \langle \mathcal{V}_E, \mathcal{E}_R, \mathcal{C}_I \rangle$$

Where:
- $\mathcal{V}_E$: Set of Entity Nodes representing domain symbols and concepts.
- $\mathcal{E}_R$: Set of Relation Edges binding entities via directional predicates.
- $\mathcal{C}_I$: Set of Invariant Rules in $S_{invariants}$ representing universal constraints and logical implications.

---

## 2. Structural Primitives

### 2.1 Entity Nodes ($\mathcal{V}_E$)
An Entity Node $e \in \mathcal{V}_E$ is defined by:
$$e = \langle \text{Symbol}, \text{Category}, \text{Properties} \rangle$$
*Example*: $e_{Whale} = \langle \text{"Whale"}, \text{"Mammal"}, \{\text{"breathes\_air"}\} \rangle$.

### 2.2 Relation Edges ($\mathcal{E}_R$)
A Relation Edge $r \in \mathcal{E}_R$ is a directed triple:
$$r = (s, p, o) \in \mathcal{V}_E \times \mathcal{P}_{rel} \times \mathcal{V}_E$$
*Example*: $(\text{Whale}, \text{is\_a}, \text{Mammal})$.

### 2.3 Invariant Rules ($\mathcal{C}_I$)
An Invariant Rule $c \in \mathcal{C}_I$ stored in $S_{invariants}$ is a universally quantified implication:
$$c = \forall x \left( P_{cond}(x, T_{cond}) \implies P_{impl}(x, T_{impl}) \right)$$
*Example*: $c_{mammal\_air} = \forall x \left( \text{is\_a}(x, \text{Mammal}) \implies \text{breathes}(x, \text{Air}) \right)$.

---

## 3. Reasoning & Proof Trace Synthesis

Reasoning over $\mathcal{K}$ executes via two complementary mechanisms:

1. **Direct Substrate Lookup**:
   Checks whether $(s, p, o) \in \mathcal{E}_R$.
2. **Deductive Invariant Unrolling**:
   If $(s, p, o) \notin \mathcal{E}_R$, searches $\mathcal{C}_I$ for matching implication rules. If rule $c$ matches $p(s, o)$, checks precondition $P_{cond}(s, T_{cond})$.
   Upon match, synthesizes an explicit, non-verbatim proof trace:
   $$\mathcal{T}_{proof} = [\text{is\_a}(s, T_{cond}), \text{Rule } c, \text{Conclusion } p(s, o)]$$

---

## 4. Counterfactual Simulation ($S'_{counter}$)

Counterfactual reasoning ("If X were Y instead of Z...") executes via local state copy and mutation without corrupting main memory:

1. **State Copy**: Instantiate $\mathcal{K}' = \text{Copy}(\mathcal{K})$.
2. **Premise Mutation**: Delete original relation $(s, \text{is\_a}, Z)$ and assert counterfactual relation $(s, \text{is\_a}, Y)$ in $\mathcal{K}'$.
3. **Re-Evaluation**: Evaluate target query over $\mathcal{K}'$. If rule preconditions fail, emit `NO` with counterfactual explanation:
   $$\text{"If } s \text{ were } Y \text{ instead of } Z\text{, the rule 'All } Z \text{ } p \text{ } o\text{' would no longer imply that } s \text{ } p \text{ } o\text{."}$$

---

## 5. Misunderstanding & Clarification Request Synthesis

When queried about an entity or property not present in $\mathcal{K}$ (e.g. "Do platypuses produce milk?"):

1. **Missing Knowledge Detection**: Identifies that $e_{Platypus} \notin \mathcal{V}_E$ or no rule connects $e_{Platypus}$ to property.
2. **State Assignment**: Transition to `CLARIFICATION_REQUIRED` state ($H = 999.0$ nats).
3. **Query Synthesis**: Formulates a targeted mentor query:
   $$\text{"I do not know what kind of entity 'Platypus' is. Is Platypus a Mammal, or does Platypus belong to another category?"}$$
4. **Knowledge Update**: Upon receiving mentor clarification ("Platypuses are mammals"), updates $\mathcal{K}$ dynamically and completes deduction.

---

## 6. Experimental Validation (EXP-026 Results)

KRS-001 and ACA-0 achieved **100.0% pass rate across 5 random seeds** on the 5-stage benchmark suite:

| Stage | Benchmark Question | ACA-0 Response | Proof / Explanation | Result |
|---|---|---|---|---|
| **Stage 1: Direct Recall** | "Do whales breathe air?" | `YES` | Direct fact stored: `Whale breathes Air` | **PASS (100%)** |
| **Stage 2: Explanation** | "Why do whales breathe air?" | `EXPLANATION` | "Because Whales are Mammals, and all Mammals breathe Air." | **PASS (100%)** |
| **Stage 3: Transfer** | "If dolphins are mammals, do dolphins breathe air?" | `YES` | "Because Dolphins are Mammals, and all Mammals breathe Air." | **PASS (100%)** |
| **Stage 4: Counterfactual** | "If whales were fish instead of mammals, would previous conclusion hold?" | `NO` | "If Whales were Fish instead of Mammals, rule 'All Mammals breathe Air' no longer implies Whales breathe Air." | **PASS (100%)** |
| **Stage 5: Clarification** | "Do platypuses breathe air?" $\to$ Clarified "Platypuses are mammals" | `CLARIFICATION_REQUIRED` $\to$ `YES` | Identifies missing knowledge $\to$ Receives clarification $\to$ `YES` (proof trace updated) | **PASS (100%)** |
