# Research Log

## Chronological Timeline

### Phase 1: The Design Model Initiative
* **Event:** Project inception.
* **Focus:** Attempting to invent a fundamentally new foundation model for design generation (specifically web design).
* **Outcome:** Encountered structural limitations in representation. Led to the development of the Council methodology for rigorous review.

### Phase 2: The CCA v0.1 Pipeline
* **Event:** Formulation of the Cognitive Computational Architecture (CCA v0.1).
* **Focus:** Establishing a rigid pipeline of cognitive functions (Observation -> Difference -> Pattern -> Concept -> etc.).
* **Outcome:** Realization that a static pipeline, while conceptually sound, fails to adapt to diverse problem structures.

### Phase 3: The Adaptive Pivot
* **Event:** Council decision to broaden the research objective beyond design and beyond static pipelines.
* **Focus:** Investigating whether intelligence requires fundamentally different computational mechanisms dynamically selected according to the nature of the problem.
* **Outcome:** Current research state. Web design relegated to an evaluation domain.

### Phase 4: Domain-Oriented Council Hierarchy
* **Event:** Refactoring of the research repository into specialized domain councils.
* **Focus:** Allowing independent research domains to evolve autonomously. Initial sprint focused on the Knowledge Foundation Council to discover the computational nature of knowledge before resuming architecture work.
* **Outcome:** The Main Council assumes oversight of mature theories, while specialized councils take over localized domains. Ran Knowledge Foundation Council Sprints 1 through 3A; produced a refined validation methodology but no validated primitive and no empirical contact with data (see DEC-005).

### Phase 5: Build-Experiment-Validate-Iterate (Current)
* **Event:** DEC-005 — pivot from council-driven first-principles derivation to empirical, code-based experimentation.
* **Focus:** Propose a small, concrete, trainable architectural mechanism; implement and test it against an honest baseline with multiple seeds; report the result — including outright falsification — before generalizing anything. Council system retained only as a diagnostic tool for root-causing experiment failures.
* **Outcome so far:** EXP-001 (surprise-gated episodic memory allocation) confirmed. EXP-002 (compositional rule module) falsified in its original form across three attempts, then confirmed in a much narrower, mechanistically-understood form (constrain the operator to the true symmetry family), with a clearly identified open problem (automatic family discovery). EXP-003 (automatic family selection) confirmed that selection must be driven by held-out generalization, not training loss, falsifying two naive alternatives in the process. Next: EXP-004, an integration test combining the validated memory and rule-module mechanisms. See `docs/06_experiments/Completed.md`.
* **2026-09-22 (GDR Cognitive Sprint):** Formulated Goal-Directed Reasoning (GDR-001). Adversarially audited and dismantled premature 7-faculty taxonomy and static PCE (GDR-002). Formulated and empirically evaluated Closed-Loop Discrepancy Reduction vs. Search in EXP-CCS-0 (GDR-003): falsified pure myopic discrepancy reduction due to deceptive local minima and epistemic blindness; confirmed heuristic tree search over isolated primitives with state rollback (SET-CR) achieves 100% composition success and runtime fault recovery.
* **2026-09-24 (Substrate Archaeology & Capability Ladder — CTX-002):** Conducted rigorous archaeological recovery of Paartha's research on state, context, memory, weights, and inference (`docs/12_cognition/CTX-002.md`). Established the Option B 7-stage progressive capability ladder ($\text{Speak} \to \text{Understand} \to \text{Brainstorm} \to \text{Plan} \to \text{Code} \to \text{Act} \to \text{General}$). Re-grounded architecture on verified three-tier state ($S_{semantic}, S_{episodic}, S_{invariants}$) and the reserved working-state partition (`WorkingStateStore`), formalizing Paartha's functional equivalents of weights, context window, KV cache, and inference. Identified the critical unsolved gap for Stage 1: lightweight natural-language ingress grounding and proof-trace surface realization.
* **2026-09-24 (JEv Study & Calibrated Decision Substrate — JEV-001):** Investigated TypeSafe AI's Jev model (System 1 non-autoregressive decision model trained via RLCD). Recovered earlier Paartha formulations of amortized risk prediction ($g_\phi(e, c) \to (\mu_c, \sigma_c)$) and routing regret, connecting them to EXP-003 and EXP-009. Determined that a calibrated decision substrate serves as Paartha's System 1 engine (Option E: front-door speech act routing, SET-CR search branch heuristics, and semantic verification) cleanly separated from System 2 deliberative search and surface realization. Formulated the minimal validating experiment (EXP-JEV-0) for Stage 1. See `docs/12_cognition/JEV-001.md`.
* **2026-09-24 (Paartha Computational Architecture Specification — PAARTHA-ARCH-001):** Derived the formal computational architecture for Stage 1 (Speak) capable of scaling across the entire 7-stage capability ladder. Formalized the 6-step universal computational primitive ($\text{Perceive} \to \text{Resolve} \to \text{Decide} \to \text{Transform} \to \text{Verify} \to \text{Update}$). Defined state formally as $\mathcal{S} = \langle \Theta, \mathcal{L}, \mathcal{K}, S_{episodic}, S_{working}, s^{hist}, S_{decision} \rangle$, inference as discrete state transitions with sandboxed rollback, and three-tier parameter allocation ($\le 1.2\text{B}$ shared weights + modular $\mathcal{L}$ + zero-parameter invariants). Designed the falsification trial EXP-SPEAK-0. See `docs/12_cognition/PAARTHA-ARCH-001.md`.
* **2026-09-24 (Competence Acquisition & Non-End-to-End Learning Trial — EXP-032):** Empirically investigated whether a system of learned/frozen representations, explicit executable capabilities, proposal-guided search, and independent verification can acquire reusable competence without end-to-end gradient updates across its neural substrate. Built minimal executable trial (`experiments/exp032_competence_accumulation/run.py`). Results: (1) Proposal-guided search reduced node exploration by 5.57x and execution count by 19.46x over uninformed BFS ($b^*$ dropped from 4.27 to 2.14); (2) Verified macro abstraction passed all 4 levels of generalization (exact, parameter, structural, compositional); (3) Longitudinal accumulation accelerated deep task search by 5.37x via subroutine reuse; (4) Counterfactual ablation achieved 100% root-cause failure attribution across 6 independent error types without backpropagation; (5) Library bloat collapsed Recall@3 to 0.000, which deduplication compression restored to 0.667; (6) Teacher distillation under an independent verification firewall successfully accepted sound procedures while rejecting hallucinated tools and semantic bugs. Proved that intelligence changes via topological growth of the verified capability library $\mathcal{L}$, while the neural substrate remains fixed ($\Delta \Theta = 0$). See `docs/12_cognition/PAARTHA-COMPETENCE-001.md`.
* **2026-09-24 (Autonomous Abstraction Discovery vs Composition Caching — EXP-033):** Falsified composition caching and empirically validated autonomous abstraction discovery via frequent motif mining, Plotkin anti-unification (parameter lifting), synthetic test verification, and Minimum Description Length (MDL) compression (`experiments/exp033_abstraction_discovery/run.py`). Results: (1) Composition caching achieved 0.0% held-out generalization, while abstraction discovery achieved 100.0% transfer across 5 strict levels (new params, new schemas, novel surrounding ops, novel task families, multi-abstraction composition); (2) Successfully passed the adversarial Frankenstein test: MDL rejected superficial syntax repetitions (`[SORT_BY -> RENAME]`, $\Delta \text{MDL} = -64\text{ bits}$); (3) Successfully demonstrated recursive hierarchical discovery ($L_0 \to L_1 \to L_2$, $\Delta \text{MDL} = +48\text{ bits}$); (4) Proved that all three components (Mining + Anti-Unification + MDL) are strictly necessary via 6-way ablation; (5) Break-even analysis proved sleep-phase consolidation cost (1.32 ms) is repaid in a single future query (~86 ms savings). Formally confirmed that Paartha can autonomously discover genuinely reusable abstractions rather than merely caching scripts. See `docs/12_cognition/PAARTHA-ABSTRACTION-001.md`.
* **2026-09-24 (Capability Selection in Non-Stationary Libraries — EXP-034):** Investigated how Paartha selects acquired capabilities as library size scales ($|\mathcal{L}| = 20 \to 1,000$). Implemented and compared 5 selection architectures: Flat Neural Classifier, Two-Tower Embedding Retrieval, Symbolic Applicability, Hybrid Selection, and Search-Only baseline (`experiments/exp034_capability_selection/run.py`). Results: (1) Interface sufficiency: external contracts achieved higher recall (0.25) than AST-exposed contracts (0.00), proving AST inspection is actively detrimental; (2) Applicability vs Selection: omitting symbolic applicability filters caused a 100.0% crash rate in two-tower embedding, whereas hybrid selection achieved 0.0% crashes; (3) Non-stationary action scaling: hybrid selection maintained stable Recall@5 (0.62) from 20 to 1,000 capabilities with sub-linear CPU retrieval latency (6.19 ms at $|\mathcal{L}|=1,000$); (4) Abstraction depth: deeper abstractions ($L_2$) achieved 100% Recall@1 (higher than primitives) due to rich multi-attribute contracts; (5) Zero-shot insertion: dynamic contract indexing achieved immediate zero-shot discovery of newly synthesized capabilities in 0.017 ms with 0 FLOPs and 0% catastrophic forgetting, falsifying the need for continuous neural retraining; (6) Adversarial distractors: under 990 distractors, flat neural and embedding collapsed to 0.0-0.2 recall, while hybrid selection retained 0.80 recall; (7) Multi-step composition: hybrid proposals collapsed depth-3 search tree from 16,275 nodes to 39 nodes (417.3x reduction); (8) Decision substrate (JEv-Lite): margin gating reduced speculative node expansions by 20.8%. Confirmed tripartite modularity: representation ($\Theta_{rep}$, frozen), computational competence ($\mathcal{L}$, dynamic discrete), and deliberation ($\Theta_{delib}$, hybrid calibrated router). See `docs/12_cognition/PAARTHA-SELECTION-001.md`.
* **2026-09-24 (Typed Parameter Binding & Joint Constraint Solving — EXP-035):** Investigated how Paartha automatically synthesizes, binds, validates, and type-checks the parameters of retrieved capabilities against state and goal (`experiments/exp035_parameter_binding/run.py`). Formulated binding as a 5-stage constraint satisfaction problem ($\text{Syntactic} \to \text{Semantic} \to \text{Typed/Unit Normalization} \to \text{Joint CSP} \to \text{Executable Verification}$). Results: (1) 4-way ablation showed System D (Hybrid Constraint Resolver) achieved 100% executable validity and 0% crash rate, whereas System B (Embedding Matcher) collapsed to 0% validity / 100% crash rate, and System A/C failed derived parameters (25% crash rate); (2) Multi-domain unit normalizer achieved 100.0% accuracy across currencies (Lakh, Crore, Million, INR, USD), percentages, and counts; (3) JEv-Lite margin gating ($\Delta < \tau$) reliably detected semantic ambiguity (branching between `spending` and `total_spending`) while immediately committing when unambiguous; (4) Proved that parameter assignments must satisfy joint CSP constraints ($p_1 \ne p_2$, $k > 0$); (5) Demonstrated zero-shot binding and execution of an unseen capability (`CAP_WINDOWED_ANOMALY`) synthesized at runtime with 0 FLOPs retraining; (6) Handled 6 distinct failure modes pre-execution; (7) Verified the complete end-to-end pipeline in 0.051 ms; (8) Formalized the irreducible computational primitive $\text{RESOLVE}(\text{Goal } G, \text{State } S, \text{CapabilityContract } C) \to \text{BoundExecutableCapability}$. See `docs/12_cognition/PAARTHA-BINDING-001.md`.
* **2026-09-24 (Communication Resolution, Pragmatic Decision & Interactive Clarification — EXP-036):** Investigated how Paartha turns an ambiguous natural language goal into a verified executable intention, knowing when to act, reason, ask, reject, or declare uncertainty (`experiments/exp036_communication_resolution/run.py`). Audited the complete pipeline and formalized missing operators ($\tau_{ingress}, \tau_{goal}, \tau_{decide}, \tau_{realize}$). Falsified the assumption that $\text{RESOLVE}$ is the front door, establishing the pre-RESOLVE decision primitive $\text{DECIDE}(G, S, \mathcal{L}, \mathcal{K}) \to \mathcal{M} \in \{\text{ANSWER}, \text{ACT}, \text{CLARIFY}, \text{EXPLAIN}, \text{REJECT}, \text{UNKNOWN}\}$. Replaced 1D scalar margins with a 6-factor Epistemic State Vector $\mathbf{E} = \langle u_{sem}, u_{epi}, u_{cap}, u_{param}, u_{auth}, u_{exec} \rangle$. Derived the Clarification Engine via Expected Information Gain ($v^* = \arg\max_v \text{EIG}(v)$), achieving $1.585\text{ bits}$ isolation of ambiguous variables. Validated multi-turn working state updates ($S_{working}$) across corrections ($50\text{L} \to 70\text{L}$), mind changes, and pronoun resolution ("their", "them", "its"). Proved canonical semantic convergence across English, Telugu script, Tenglish, Hindi script, Hinglish, and Code DSL. Evaluated an 80-scenario benchmark across 5 architectures: System E (Full Paartha Tripartite) achieved 100.0% accuracy (80/80) with 0 crashes, 0 safety violations, and 0.21 ms latency, outperforming Monolithic LLMs (38.8%, 3 safety violations), Intent-Slot pipelines (31.2%, 4 crashes), and JEv baseline variants (37.5% - 40.0%). Mapped 208 baseline failures into the 9-class failure taxonomy and proved modular learning attribution ($\Delta \Theta_{trans}, \Delta \Theta_{decision}, \Delta \mathcal{L}, \Delta \mathcal{K}, \Delta S$) with zero catastrophic forgetting. See `docs/12_cognition/PAARTHA-COMM-001.md`.
* **2026-09-26 (Adversarial Generalization Audit & Benchmark Leakage Falsification Trial — EXP-037):** Conducted an adversarial falsification audit of EXP-036 to determine whether Stage 1 (Speak & Communicate) was genuinely solved or reflected benchmark overfitting (`experiments/exp037_adversarial_generalization/run.py`). Results: (1) Confirmed 5 severe benchmark leakages in EXP-036 (hardcoded domain lexicons, exact string checks, fixed entity sets); (2) Evaluated against 96 un-leaked scenarios across 8 held-out domains: the EXP-036 pipeline collapsed to 8.33% accuracy (8/96) with 25 runtime crashes; a strong ReAct-style neural tool agent achieved 32.29% accuracy (31/96) but committed 4 critical safety violations; the generalized contract-driven Paartha architecture achieved 86.46% accuracy (83/96) with 0 crashes and 0 safety violations; (3) Validated 10 structurally diverse capability archetypes (C1–C10) via typed contracts without AST inspection; (4) Falsified the sufficiency of the 6D epistemic vector $\mathbf{E}$ across 7 unrepresentable boundary cases (contradictory multi-source evidence, temporal expiration, model divergence, planning horizon risk); (5) Falsified pure Max-EIG clarification due to user alienation on high-entropy technical variables; validated a hybrid cost-penalized EIG objective ($J = \text{EIG} - \lambda \cdot C_{effort}$); (6) Falsified flat working memory; proved multi-turn discourse requires a Hierarchical Discourse DAG; (7) Supported multilingual convergence (93.3% accuracy, 14/15) across Telugu, Hindi, Tenglish, Hinglish, and Code DSL on held-out schemas; (8) Confirmed the 7-state computational lattice (ANSWER, ACT, CLARIFY, RETRIEVE, VERIFY, REJECT, UNKNOWN) with orthogonal invariants; (9) Proved modular learning isolation and 0.0% catastrophic forgetting across a 6-phase curriculum; (10) Resolved architectural ontology: Paartha is not a monolithic model, but a Cognitive Computational Architecture; (11) Issued a Conditional Go with mandatory remediations for Stage 2. See `docs/12_cognition/PAARTHA-ADVERSARIAL-001.md`.
* **2026-09-26 (Paartha Mechanism Ablation — Causal Isolation of Runtime Mechanisms — ABLATION-001):** Executed a strictly controlled mechanism ablation matrix (A1 through A9) and parameter sweeps (Search budget $k \in [0..16]$, Verification levels, RESOLVE tiers) using live `sarvam-105b-conversations` API across held-out logistics and cross-domain spectroscopy tasks (`experiments/mechanism_ablation/run_ablation.py`). Results: (1) Single-shot LLM Alone (A1) achieved only 33.3% success (0.555 F1) due to in-context calculation drift (`MODEL_LIMITATION`); (2) Standard ReAct primitive tool use (A2) achieved 50.0% success (0.795 F1); (3) System A6 (LLM + Tools + SET-CR Search & Rollback) achieved **83.3% success** and **0.967 F1** with **0 invalid tool calls**, vastly outperforming the full Paartha runtime A9 (33.3%); (4) Discovered the "RESOLVE Distortion Effect": heuristic column fallbacks (`list(num_cols)[0]`) in RESOLVE silently mutate user intent on structured schemas without raising exceptions, defeating rollback and degrading performance from 75% to 50%; (5) Proved that search budget depth ($k$) does not expand intrinsic problem-solving capability (accuracy stayed flat at 50% from $k=0$ to $k=16$ with constant 12-13 expansions), functioning strictly as an exception-recovery buffer; (6) Conclusively answered the causal question: Paartha's runtime advantage is primarily caused by **SET-CR state checkpointing & exception rollback** operating over deterministic tools. See [`docs/12_cognition/PAARTHA-MECHANISM-ABLATION-001.md`](file:///d:/Paartha/adaptive-computational-architecture/docs/12_cognition/PAARTHA-MECHANISM-ABLATION-001.md).
* **2026-09-26 (Genuine Abstraction Transfer Across Independent Domains — TRANSFER-001):** Conducted a controlled multi-domain transfer benchmark across three completely non-co-designed domains: Domain A (Logistics), Domain B (Molecular Spectroscopy), and Domain C (Financial Market Microstructure & Order Execution), verified with 0 leaks via static audit (`experiments/abstraction_transfer/run_transfer.py`). Evaluated whether abstractions discovered in Domain A transfer based on structural isomorphism under fair, non-overloaded JSON Schema baseline interfaces. Results: (1) In Domain A, strict MDL rejected the 6-parameter candidate macro (`Composite_Filter_Sort_TopK`, $\Delta \text{MDL} = -32\text{ bits}$), preventing library bloat from superficial repetitions; (2) In novel Domains B & C, cross-domain transfer ratios ($D / B_1$) collapsed to **1.00x** (Domain B: 66.7% vs 66.7%; Domain C: 66.7% vs 66.7%); (3) Discovered macro abstractions were invoked **0 times** in novel domains; (4) Deep diagnostic analysis proved that System B2's failures were 100% caused by `CAPABILITY_SELECTION` (the frontier LLM naturally decomposes tasks into sequential primitive tool calls rather than composite macros); (5) Established the fundamental distinction between **Runtime Generalization** (CONFIRMED: SET-CR state rollback enables high-fidelity multi-step execution in unfamiliar domains, 0.844 - 0.933 F1) and **Learned Computational Generalization** (FALSIFIED in current architecture: autonomous macro discovery does not produce cross-domain transfer). Concluded that Paartha is currently a verified, exception-safe tool-execution runtime rather than a cross-domain abstraction learning engine.
